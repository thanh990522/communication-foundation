Tiến độ học viên

Học viên nhập tên ở trang chủ → mỗi lần mở bài học / nộp homework sẽ được ghi vào Google Sheet của bạn.

Đóng / mở bài học

Bật = học viên thấy và vào học được. Tắt = bài bị khoá (kể cả khi có link trực tiếp). Lưu xong khoảng 1 phút trang học viên cập nhật.

1 · GitHub key (để đóng / mở bài)

Key chỉ lưu trên trình duyệt này, không gửi đi đâu ngoài GitHub.

  1. Mở github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: giao-tiep-admin · Expiration: chọn thời hạn bạn muốn.
  3. Repository access: Only select repositories → communication-foundation.
  4. Permissions → Repository permissions → Contents: Read and write → Generate token → copy.

2 · Google Sheet (để theo dõi tiến độ)

  1. Tạo một Google Sheet mới (vd. GT246 Progress) → menu Extensions → Apps Script.
  2. Xoá code mẫu, dán toàn bộ code bên dưới. Đổi dòng ADMIN_KEY thành mật khẩu riêng của bạn → 💾 Save.
  3. Deploy → New deployment → chọn loại Web app · Execute as: Me · Who has access: Anyone → Deploy → cho phép quyền truy cập.
  4. Copy Web app URL (dạng https://script.google.com/macros/s/…/exec) → dán vào ô dưới → Lưu.
Đang tải…
Web app URL (lưu lên website để học viên gửi tiến độ)
Mật khẩu ADMIN_KEY (chỉ lưu trên trình duyệt này)

3 · Thiết bị giáo viên

Thiết bị được đánh dấu là giáo viên sẽ luôn xem được bài đã đóng và không bị hỏi tên.
