A1 → A2 Communication Accelerator · S0808
Structure 1 / 4

Do you have this in ___?

🇻🇳 Bạn có cái này cỡ / màu ___ không?
→ Yes, we do. / Sorry, we only have it in ___.
🇻🇳 Có. / Xin lỗi, chúng tôi chỉ có cỡ / màu ___.
QDo you have this in a medium?
💬 Common answers
a
Yes, we do. Here you are.Có. Của bạn đây.
b
Sorry, we only have it in small and large.Xin lỗi, chúng tôi chỉ có cỡ nhỏ và lớn.
c
Let me check. Yes, we have it in blue, too.Để tôi kiểm tra. Có, chúng tôi cũng có màu xanh dương.
⚡ Translate now · Dịch ngay
1🇻🇳 Bạn có đôi giày này cỡ 40 không?
🇬🇧 Do you have these shoes in a size 40?
2🇻🇳 Bạn có áo khoác này màu đen không?
🇬🇧 Do you have this jacket in black?
3🇻🇳 Xin lỗi, chúng tôi chỉ có cỡ vừa.
🇬🇧 Sorry, we only have it in a medium.

Structure 3 / 4

It's too ___. / It isn't ___ enough.

🇻🇳 Nó quá ___. / Nó không đủ ___.
→ Would you like a bigger / smaller size?
🇻🇳 Bạn có muốn cỡ lớn hơn / nhỏ hơn không?
QHow does it fit?
💬 Common answers
a
It's too small. Do you have a bigger size?Nó quá nhỏ. Bạn có cỡ lớn hơn không?
b
It isn't long enough.Nó không đủ dài.
c
It's too expensive for me.Nó quá đắt đối với tôi.
⚡ Translate now · Dịch ngay
1🇻🇳 Đôi giày này quá to.
🇬🇧 These shoes are too big.
2🇻🇳 Chiếc áo khoác này không đủ ấm.
🇬🇧 This jacket isn't warm enough.
3🇻🇳 Nó quá đắt, vì vậy tôi không mua.
🇬🇧 It's too expensive, so I'm not buying it.

Structure 4 / 4

I'd like to exchange / return ___.

🇻🇳 Tôi muốn đổi / trả lại ___.
→ Do you have the receipt? / You can get a refund.
🇻🇳 Bạn có biên lai không? / Bạn có thể được hoàn tiền.
QCan I help you?
💬 Common answers
a
I'd like to return this jacket. The zip is broken.Tôi muốn trả lại chiếc áo khoác này. Khóa kéo bị hỏng.
b
I'd like to exchange these jeans for a bigger size.Tôi muốn đổi chiếc quần jean này lấy cỡ lớn hơn.
c
It's a damaged product. Can I get a refund?Đây là sản phẩm bị hỏng. Tôi được hoàn tiền không?
⚡ Translate now · Dịch ngay
1🇻🇳 Tôi muốn đổi chiếc áo sơ mi này lấy màu khác.
🇬🇧 I'd like to exchange this shirt for a different colour.
2🇻🇳 Tôi muốn trả lại đôi giày này. Đây là biên lai.
🇬🇧 I'd like to return these shoes. Here's the receipt.
3🇻🇳 Tôi có được hoàn tiền không?
🇬🇧 Can I get a refund?
